LIVE WEBSITE

Live Website Control

Control what the retail website is allowed to show without changing the master catalogue used for valuations and research.

VIEW ONLY LIVE WEBSITE PRODUCTSSTAFF DASHBOARD
READ-ONLY ACCESS. Sales and Purchasing staff can inspect the current website visibility, but only Management can change it.

HOW VISIBILITY WORKS

Manufacturer → category → individual product

Hide at any level removes it from the public retail website. Show explicitly allows it. Auto removes the override and returns to the normal storefront rule. These controls affect the retail website only; they do not deactivate catalogue products for valuations.

Example: use SHOW ONLY SELECTED MANUFACTURERS with DJI selected, then SHOW ONLY SELECTED CATEGORIES with Drones selected. The live storefront will then expose DJI drones while cameras, accessories and other manufacturers/categories are hidden.
