AI RESEARCH PC

Setup, startup and restart instructions

Open this guide when the Research PC has been restarted, the worker is stopped, or the dashboard shows OFFLINE.

VIEW GUIDE

The current Research PC uses a persistent Windows launcher and supervisor. Supabase stores the queue, the supervisor keeps the control channel available, and agent.mjs runs the actual research worker with Ollama gemma3:4b. Permanent configuration remains outside the repository.

1. Normal startup or after a PC restart

Use the established Windows desktop launcher, which runs:

C:\GearCashOut-Config\Start-GearCashOut-AI.ps1

The launcher starts the persistent supervisor, which then controls the research worker. Do not run npm start from C:\GearCashOut-Config; that folder contains configuration, not package.json.

2. If the dashboard says OFFLINE

OFFLINE means the Research PC supervisor is not available. Start the Windows desktop launcher above and wait for the dashboard to report READY or ONLINE.

Once the dashboard shows READY, the supervisor is online and the worker can be started remotely.

3. Start, stop and restart from the dashboard

START RESEARCH PC WORKER starts agent.mjs through the running supervisor.

STOP ALL RESEARCH & WORKER stops the worker and active research but deliberately leaves the supervisor available, so the dashboard can start the worker again later.

RESTART RESEARCH PC WORKER restarts the worker through the supervisor.

4. Check Ollama and the model

If research cannot process jobs, check:

ollama list

The configured model should include:

gemma3:4b

To test directly:

ollama run gemma3:4b

Then type /bye to exit.

5. Where the worker actually runs

The default extracted repository location is:

C:\gearcashout\Action-Buyer-UK-main\tools\gear-ai-local-agent

The permanent configuration is:

C:\GearCashOut-Config\.env

The launcher can use GEARCASHOUT_AGENT_DIR if the extracted repository is moved.

6. If the worker will not start

Missing package / ERR_MODULE_NOT_FOUND: open the actual agent folder and run:

cd C:\gearcashout\Action-Buyer-UK-main\tools\gear-ai-local-agent
npm install

Then restart using the established Windows launcher. A normal Windows restart does not normally require npm install unless packages are missing or the repository was freshly replaced.

Check Node.js with node --version and Ollama with ollama --version.

7. Updating the local worker safely

The Research PC is a manually extracted repository copy, not a live Git checkout. Replace only the required worker files when an update is made.

Keep this file unchanged:

C:\GearCashOut-Config\.env

Never overwrite permanent configuration with a blank repository copy. Run npm install only when dependencies/package files changed or after a fresh extraction.

8. Quick reference

PC restarted / dashboard OFFLINE: start C:\GearCashOut-Config\Start-GearCashOut-AI.ps1 using the desktop launcher.

Dashboard READY: use START RESEARCH PC WORKER.

Need to stop research: use STOP ALL RESEARCH & WORKER; the supervisor remains ready for a later start.

Need full local shutdown: close the Windows launcher/supervisor session.
