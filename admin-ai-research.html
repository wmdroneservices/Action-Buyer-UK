AI RESEARCH PC

Setup, startup and restart instructions

Open this guide whenever the local AI worker has been stopped or the research PC has been restarted.

VIEW GUIDE

The website queues research jobs in Supabase. Your local research PC processes those jobs using Ollama and gemma3:4b. Keep the PowerShell window open while research is running.

1. Normal startup

Open Windows PowerShell, then copy and paste:

cd C:\gearcashout\Action-Buyer-UK-main\tools\gear-ai-local-agent
npm start

Wait for:

Ready. Polling every 15 seconds.

2. After restarting the PC

A normal Windows restart does not normally require npm install. Open PowerShell and run:

cd C:\gearcashout\Action-Buyer-UK-main\tools\gear-ai-local-agent
npm start

The worker will automatically reconnect and check for queued research jobs.

If you see ERR_MODULE_NOT_FOUND, a missing package error, or you have just replaced/downloaded the repository, run npm install once and then run npm start.

3. Check Ollama and the AI model

If the worker cannot process research, check that Ollama and the model are available:

ollama list

You should see:

gemma3:4b

To test the model directly:

ollama run gemma3:4b

Then type /bye to exit.

4. Stop the worker

Click inside the running PowerShell window and press:

Ctrl + C

This stops only the local research worker. The website and database remain online.

5. How research works

  1. Select products or filters above.
  2. Click RUN SELECTED AI RESEARCH.
  3. The website queues the products.
  4. The local PC claims and researches each product.
  5. Findings return as proposed evidence.
  6. Review, edit, accept or deny each entry.
  7. Only accepted evidence is applied to the live evidence base.

6. If the worker will not start

Missing package / ERR_MODULE_NOT_FOUND:

cd C:\gearcashout\Action-Buyer-UK-main\tools\gear-ai-local-agent
npm install
npm start

This usually happens after downloading/replacing the repository or when the local node_modules folder is missing. It is not normally caused simply by restarting Windows.

Check Node.js:

node --version

Check Ollama:

ollama --version

7. Updating the local worker

Check Node.js:

node --version

Check Ollama:

ollama --version

Install dependencies after a major worker update:

cd C:\gearcashout\Action-Buyer-UK-main\tools\gear-ai-local-agent
npm install

7. Updating the local worker

Before replacing files, stop the worker with Ctrl + C. Keep your existing .env file — do not overwrite it with a blank version from a GitHub ZIP download.

If package.json changes, or you are using a freshly extracted repository, run npm install before starting the worker again.

Do not overwrite your existing .env file.
